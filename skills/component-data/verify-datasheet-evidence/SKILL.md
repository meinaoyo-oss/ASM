# 数据手册证据核验

MCP 覆盖：`external`。当前 MCP 不提供可信的数据手册抓取、OCR 或页码级语义核验；需要人工提供文档或接入受控的文档检索系统。

## 工作流

1. 记录制造商、完整 MPN、数据手册版本或日期、文件哈希和来源 URL；型号不完整时先停止核验。
2. 对每个影响设计的字段建立“值、单位、原文页码/章节、核验状态”记录。优先核对引脚功能、电气极限、工作范围、封装尺寸、公差、Pin 1、热焊盘和推荐 land pattern。
3. 将数据手册原文、库对象和 BOM 字段逐项比较；把直接证据、工程推断和待确认内容分开。
4. 遇到不同版本、选型后缀、封装变体或单位冲突时，标记为 `fail` 或待人工确认，不选择看起来最接近的值。
5. 记录未使用引脚、热设计、替代料和封装兼容性对原理图、PCB 和制造文件的影响。

## 边界

- 不从搜索摘要、经销商页面或相似型号推导绝对最大额定值和封装尺寸。
- 不自动生成可用于生产的符号、封装或 3D 模型，除非每个关键字段都有可追溯证据。
- 数据手册不能证明整板符合 EMC、安规或可靠性要求。

## 输出

输出字段核验表、引用位置、来源哈希、冲突、缺失证据、受影响设计对象和下一步人工确认项；缺少关键页码证据时不得标记为完整通过。

# EMC 风险审查

MCP 覆盖：`external`。PCB MCP 可提供层文件和 ERC/DRC 证据，但不能替代 EMC 计算、暗室/台架测试、法规限值或专业整改判断。

## 工作流

1. 固定产品版本、适用标准/限值、工作模式、线缆和外部接口；没有目标标准时只输出风险清单，不输出合规结论。
2. 结合原理图、层叠、布局和发布文件检查时钟与高速边沿、回流路径、分割平面、环路面积、连接器、共模路径、滤波/TVS、屏蔽、机壳和接地策略。
3. 使用 `pcb_inspect_package`、`pcb_validate_gerber_set` 和 `pcb_run_kicad_checks` 作为文件证据；将工具未覆盖的辐射、抗扰度和线缆耦合风险单独标记。
4. 按潜在影响和证据强度排序，给每项风险绑定设计位置、可能耦合路径、建议措施、验证方法和关闭条件。
5. 不直接修改布局、规则或滤波参数；整改后必须重新生成发布证据并安排相应预扫或认证测试。

## 输出

输出风险等级、证据位置、影响模式、建议整改、验证仪器/工况、通过限值、残余风险和人工责任人。没有测试数据时明确写为“设计风险评估”，不得写成 EMC 合规证明。

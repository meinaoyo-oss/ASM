# BOM 风险审查

MCP 覆盖：`partial`。本地 MCP 可校验 BOM 结构并标记生命周期、供应来源和替代料证据缺口；库存、价格、交期和真伪风险仍需要经授权的供应商/分销商 API 或人工证据。

## 工作流

1. 固定 BOM 版本、导出时间、制造商和完整 MPN；保留原始字段，不用模糊描述替换型号。
2. 标准化制造商、MPN、封装、数量、位号和 DNP 标记，同时保留标准化前后的映射。
3. 对每个关键料分类：生命周期状态、单一来源、替代料可用性、交期/库存证据、关键电气参数、封装与工艺兼容性。
4. 只有带查询时间、接口来源或供应商文件的结果才能作为实时供应结论；过期或无来源的信息标记为 `unknown`。
5. 将风险分为阻断量产的 `critical`、需要批准的 `high`、需跟踪的 `medium` 和信息项，并给出可验证的缓解措施。

## 边界

- 不因存在同封装或相似料号就认定可替代；必须核对电气、温度、引脚、机械和制造工艺约束。
- 不自动替换 BOM、批准替代料、下单或改变 AVL；替代料必须经过工程和质量批准。
- 不将供应商网页缓存作为长期证据，报告必须带时间戳和来源哈希或链接。

## 输出

输出逐料风险表、证据时间、替代候选及差异、阻断项、缓解建议和责任人。没有实时供应数据时明确声明覆盖范围，而不是给出确定的可供货结论。
